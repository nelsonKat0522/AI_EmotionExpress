\# EmoExpress



AI-powered emotional support application using Emotion Classification,

Topic Classification, Retrieval-Augmented Generation (RAG),

Large Language Models, and AI Image Generation.



\## Technologies



\- GoEmotions

\- Logistic Regression

\- Linear SVM

\- Bi-LSTM

\- DistilBERT

\- RoBERTa

\- OpenAI API

\- LangChain

\- Chroma

\- Streamlit

\- Docker
